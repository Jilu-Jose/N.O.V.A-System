About N.O.V.A System

The Neural Orbital Vigilance & Analytics (N.O.V.A) system is an advanced satellite health monitoring platform that leverages multiple machine learning algorithms to predict potential faults in satellite systems before they occur. This predictive maintenance approach helps prevent catastrophic failures and ensures continuous satellite operations.

Project Overview

This project combines hardware sensor integration with sophisticated machine learning models to create a comprehensive satellite health monitoring solution. The system collects real-time data from various sensors and processes it through multiple classification algorithms to detect anomalies and predict potential failures.

Hardware Architecture

The project utilizes an Arduino UNO microcontroller as the central hardware core, interfaced with a high-precision sensor suite:

Multiple sensors are interfaced with the Arduino to collect critical satellite health parameters:

Temperature Sensor

Monitors ambient and component temperatures to detect overheating conditions that could lead to system failures. Critical for thermal management in the vacuum of space.

Humidity Sensor

Measures relative humidity levels to prevent moisture-related damage in electronic components. Essential for detecting environmental control issues.

Ultrasonic Sensor

Provides distance measurements for proximity detection and collision avoidance. Simulates ranging sensors used in orbital positioning systems.

Gas Sensor (MQ Series)

Detects harmful gas concentrations that could indicate electrical fires or component degradation. Critical for early fire detection in enclosed satellite systems.

Radiation Sensor

Monitors ionizing radiation levels that can damage electronics in space. Tracks cumulative radiation exposure affecting satellite longevity.

IR Sensor (Infrared)

Detects infrared radiation for thermal imaging and object detection. Used for monitoring component temperatures without physical contact.

Dataset

Dataset Generation

Initial data was collected from the Arduino sensor module under various simulated conditions. A Python script was then developed to augment this baseline data, generating a comprehensive dataset with realistic variations and edge cases. This synthetic data generation approach allowed us to create a robust training dataset covering scenarios that would be difficult or dangerous to replicate in real hardware testing.

The final dataset includes 16 features (after dropping the timestamp column) representing various satellite health parameters, with a binary target variable (fault_flag) indicating whether a fault condition is present. This balanced dataset enables the machine learning models to learn patterns associated with both normal operations and fault conditions.

Machine Learning Pipeline

Seven different classification algorithms were trained on the dataset, each offering unique strengths in pattern recognition. This ensemble approach provides robust fault detection by combining multiple perspectives on the data. When predictions disagree, the system uses majority voting to determine the final classification, significantly reducing false positives and negatives.

Machine Learning Algorithms

Decision Tree Classifier

A tree-based model that makes decisions by splitting data based on feature values. Highly interpretable and excellent for understanding which features are most important for fault detection. Works by creating a flowchart-like structure where each internal node represents a test on a feature, each branch represents the outcome, and each leaf node represents a class label.

Advantages: Easy to interpret, handles both numerical and categorical data, requires little data preprocessing.

K-Nearest Neighbors (KNN)

A non-parametric method that classifies data points based on the classes of their nearest neighbors. The algorithm finds the K closest training examples and assigns the most common class among them. Particularly effective for pattern recognition in sensor data where similar readings indicate similar conditions.

Advantages: Simple to understand, no training phase required, adapts well to new patterns in data.

Logistic Regression

A statistical model that uses a logistic function to model binary outcomes. Despite its name, it's a classification algorithm that estimates probabilities using a sigmoid function. Excellent for baseline performance and understanding feature relationships. Provides probability scores for predictions.

Advantages: Computationally efficient, provides probability estimates, less prone to overfitting with proper regularization.

Multi-Layer Perceptron (MLP) Neural Network

A feedforward artificial neural network with multiple layers of neurons. Capable of learning complex non-linear relationships in the data through backpropagation. The network consists of an input layer, one or more hidden layers, and an output layer, with each connection having an associated weight that's adjusted during training.

Advantages: Learns complex patterns, handles high-dimensional data well, can approximate any continuous function.

Random Forest Classifier

An ensemble learning method that constructs multiple decision trees during training and outputs the mode of their predictions. Reduces overfitting by averaging multiple trees and provides robust performance across various datasets. Each tree is trained on a random subset of features and data.

Advantages: Highly accurate, handles missing values well, provides feature importance rankings, resistant to overfitting.

Support Vector Classifier (SVC)

A powerful algorithm that finds the optimal hyperplane separating different classes in high-dimensional space. Uses kernel tricks to handle non-linear decision boundaries. Particularly effective when there's a clear margin of separation between classes, making it ideal for binary fault detection.

Advantages: Effective in high dimensions, memory efficient, versatile through different kernel functions.

XGBoost Classifier

An optimized gradient boosting algorithm that builds an ensemble of weak prediction models (typically decision trees) in a sequential manner. Each new tree corrects errors made by previous trees. Known for its speed, performance, and regularization capabilities. Widely used in machine learning competitions due to its exceptional accuracy.

Advantages: Superior performance, handles missing data, built-in regularization prevents overfitting, parallel processing for speed.

Arduino Hardware Components

Arduino UNO Board

The Arduino UNO is a microcontroller board based on the ATmega328P. It serves as the brain of our data acquisition system, featuring 14 digital input/output pins, 6 analog inputs, a 16 MHz ceramic resonator, a USB connection, a power jack, an ICSP header, and a reset button.

Specifications: Operating Voltage: 5V, Input Voltage: 7-12V, Digital I/O Pins: 14, Analog Input Pins: 6, Flash Memory: 32 KB, SRAM: 2 KB, Clock Speed: 16 MHz.

Role in Project: Collects data from all connected sensors, performs initial data processing, and transmits readings to the computer via serial communication for dataset generation.

DHT11/DHT22 Temperature & Humidity Sensor

Digital sensor that measures temperature and relative humidity. Uses a capacitive humidity sensor and a thermistor to measure the surrounding air. Provides calibrated digital signal output through a single-wire interface.

Applications: Monitors environmental conditions inside satellite compartments, detects thermal anomalies, tracks humidity levels that could affect electronics.

HC-SR04 Ultrasonic Sensor

Non-contact distance measurement sensor using ultrasonic waves. Emits ultrasonic pulses and measures the time taken for echoes to return, calculating distance based on the speed of sound.

Applications: Proximity detection, collision avoidance simulation, measuring vibration amplitude through distance changes, deployment mechanism monitoring.

MQ-2/MQ-135 Gas Sensor

Semiconductor gas sensor that detects various gases including LPG, propane, methane, hydrogen, alcohol, smoke, and carbon dioxide. Changes resistance based on gas concentration, providing analog voltage output.

Applications: Early fire detection, outgassing detection from materials, air quality monitoring, identifying electrical component failures through unusual gas emissions.

IR Sensor Module

Infrared proximity sensor that detects objects and measures infrared radiation. Consists of an IR LED transmitter and a photodiode receiver. Can operate in both digital (object detection) and analog (distance measurement) modes.

Applications: Non-contact temperature monitoring, object detection, tracking solar panel orientation, detecting mechanical failures through thermal signatures.

Geiger Counter / Radiation Sensor

Detects ionizing radiation including alpha, beta, and gamma particles. In our simulation, we model radiation exposure levels that satellites experience in various orbital environments.

Applications: Cumulative radiation dose tracking, identifying high-radiation zones, predicting component degradation due to radiation exposure, ensuring safety margins.
